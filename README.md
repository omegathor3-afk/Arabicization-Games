# ARABIFY — Offline Android Game Localization

مشروع لبناء محرك تعريب محلي لألعاب وتطبيقات Android: تحليل APK، اكتشاف المحرك، استخراج النصوص، ترجمتها محليًا، معالجة العربية، ثم إعادة البناء عندما تسمح بنية اللعبة بذلك.

## الوضع الحالي — 0.1.0
- تطبيق Android أصلي Kotlin + Jetpack Compose.
- استيراد APK عبر Storage Access Framework.
- تحليل ZIP محليًا دون رفع الملف.
- قراءة بيانات الحزمة والإصدار عند توفرها.
- اكتشاف أولي لمؤشرات Unity وUnreal وGodot وHTML5 وAndroid Native.
- اكتشاف ملفات نصية محتملة داخل assets وres/raw ومجلدات الترجمة.
- عرض عينات نصية وحدود الفحص.
- اختبارات وحدة وGitHub Actions.

## حدود صريحة
هذا الإصدار ليس مترجم ألعاب ولا يعيد بناء APK. لا يفك resources.arsc أو DEX أو Unity bundles أو Unreal PAK/IoStore، ولا يتعامل مع ملفات مشفرة أو محمية. اكتشاف المحرك استدلال أولي.

## مبادئ
1. معالجة محلية افتراضيًا.
2. لا ندّعي اكتمال التعريب مع وجود نصوص لم نستخرجها.
3. لا نتجاوز DRM أو مكافحة الغش أو حماية المحتوى.
4. الحفاظ على النسخة الأصلية.
5. اختبار كل مرحلة قبل اعتبارها جاهزة.

## البناء
JDK 17 وAndroid SDK 36 وGradle 8.13:
- gradle testDebugUnitTest
- gradle assembleDebug
