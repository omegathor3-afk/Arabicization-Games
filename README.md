# ARABIFY — Offline Android Game Localization

تطبيق Android لمعالجة ملفات الألعاب محليًا، واكتشاف محركها، واستخراج النصوص، وتجهيز موارد عربية وإعادة بناء APK عندما تكون بنية اللعبة مدعومة.

## الإصدار 0.2.0 — ما تم تنفيذه

- تطبيق Android أصلي باستخدام Kotlin وJetpack Compose.
- استيراد APK عبر Storage Access Framework دون صلاحيات تخزين واسعة.
- فحص ZIP محليًا واستخراج بيانات الحزمة والإصدار.
- اكتشاف أولي لمؤشرات Unity وUnreal وGodot وHTML5 وAndroid Native.
- استخراج عينات من ملفات النصوص الواضحة في بعض مسارات assets.
- ترجمة محلية من الإنجليزية إلى العربية باستخدام ML Kit بعد تنزيل نموذج اللغة مرة واحدة عبر Wi-Fi.
- حماية متغيرات الألعاب مثل `{player}` و`%1$d` ووسوم التنسيق أثناء الترجمة.
- مسار تجريبي لتعريب موارد `string` الافتراضية لتطبيقات Android الأصلية وإضافة Locale `ar` إلى `resources.arsc` باستخدام ARSCLib.
- إعادة بناء APK وإزالة التوقيع القديم، ثم توقيع الناتج بمفتاح خاص بالتطبيق في Android Keystore والتحقق من التوقيع باستخدام apksig.
- اختبارات وحدة وGitHub Actions لبناء APK.

## حدود الإصدار الحالي — مهم

هذا ليس بعدُ مترجمًا عامًا لكل الألعاب:
- مسار إعادة البناء الحالي يترجم موارد Android من النوع `string` فقط، وليس النصوص داخل DEX أو الصور أو الصوت أو ملفات الألعاب الثنائية.
- لا يوجد بعد محول مكتمل لـ Unity Mono/IL2CPP أو Unreal أو Godot.
- لا يتم حاليًا تعريب `plurals` أو `string-array` أو XML أو ملفات localization الخاصة بمحركات الألعاب.
- محرك الترجمة الحالي مضبوط للإنجليزية إلى العربية؛ اختيار اللغة المصدر واكتشافها تلقائيًا قيد التطوير.
- لا يدعم تجاوز DRM أو التشفير أو أنظمة مكافحة الغش.
- التوقيع الجديد مختلف عن توقيع اللعبة الأصلية؛ قد يتطلب تثبيت النسخة المعربة إزالة النسخة الأصلية أولًا، ما قد يؤدي لفقد بياناتها. احتفظ بنسخة احتياطية.

## التشغيل والبناء

- Android 12+ (API 31+).
- إصدار APK الحالي مخصص لمعمارية `arm64-v8a` لتقليل الحجم.
- يلزم تنزيل نموذج الترجمة مرة واحدة عبر Wi-Fi؛ بعد ذلك يمكن استخدام الترجمة على الجهاز دون اتصال.
- JDK 17 وAndroid SDK 36 وGradle 8.13 للبناء.
