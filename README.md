# ARABIFY — Offline Android Game Localization

تطبيق Android لمعالجة ملفات الألعاب محليًا، واكتشاف محركها، واستخراج النصوص، وتجهيز موارد عربية وإعادة بناء APK عندما تكون بنية اللعبة مدعومة.

## الإصدار 0.2.0 — ما تم تنفيذه

- تطبيق Android أصلي باستخدام Kotlin وJetpack Compose.
- استيراد APK عبر Storage Access Framework دون صلاحيات تخزين واسعة.
- فحص ZIP محليًا واستخراج بيانات الحزمة والإصدار.
- فحص خطوط TTF/OTF المضمنة وقراءة جداول cmap لتغطية الحروف العربية، مع التحقق من سجلات `arab` في OpenType GSUB/GPOS قبل ترشيح الخط. هذا فحص بنيوي لا يثبت صحة التشكيل في محرك اللعبة.
- اكتشاف أولي لمؤشرات Unity وUnreal وGodot وHTML5 وAndroid Native. الاكتشاف لا يعني وجود محول تعريب للمحرك.
- استخراج عينات من ملفات النصوص الواضحة في بعض مسارات assets.
- ترجمة محلية من الإنجليزية إلى العربية باستخدام ML Kit بعد تنزيل نموذج اللغة مرة واحدة عبر Wi-Fi.
- حماية متغيرات الألعاب مثل `{player}` و`%1$d` ووسوم التنسيق أثناء الترجمة.
- مسار تجريبي لتعريب موارد `string` الافتراضية لتطبيقات Android الأصلية وإضافة Locale `ar` إلى `resources.arsc` باستخدام ARSCLib.
- إعادة بناء APK وإزالة التوقيع القديم، ثم توقيع الناتج بمفتاح خاص بالتطبيق في Android Keystore والتحقق من التوقيع باستخدام apksig.
- اختبارات وحدة وGitHub Actions لبناء APK.

## Unity Mono — أول محول محدود النطاق

أُضيف محول أولي لمسار Unity Mono يكتشف وجود `assets/bin/Data/Managed/Assembly-CSharp.dll` ويرفض حزم IL2CPP عند ظهور `libil2cpp.so` أو `global-metadata.dat`. يمكنه إعادة بناء APK عبر مسار ZIP والتوقيع الحالي عندما تكون النصوص في ملفات واضحة مدعومة (JSON/TXT/Properties/Strings) داخل `assets/`، بما فيها StreamingAssets.

**هذا ليس بعدُ محولًا كاملًا لملفات Unity:** لا يغيّر CIL داخل Assembly-CSharp.dll، ولا يقرأ أو يعيد بناء `resources.assets` أو AssetBundles. ملفات DLL والموارد الثنائية تُحفظ كما هي. أضيفت اختبارات ZIP fixture لتأكيد اكتشاف Mono/IL2CPP وحفظ DLL وعدم إفساد موارد النصوص. يلزم اختبار لعبة Mono حقيقية قبل توسيع الادعاء بالتوافق.

## UnityFS — فك ضغط وتحليل كتل محدود الذاكرة

أُضيف قارئ UnityFS للقراءة فقط، ويعمل على ملف Bundle كامل:
- يقرأ ترويسة UnityFS ويتحقق من الحجم المعلن، وموقع Block Info سواء جاء قبل البيانات أو في نهاية الملف، ومحاذاة 16 بايت لإصدارات التنسيق التي تتطلبها.
- يفك ضغط Block Info باستخدام LZMA أو LZ4/LZ4HC أو يقرأه دون ضغط، ثم يتحقق من أعداد الكتل والعُقد والمسارات ونطاقات offsets/sizes.
- يفك كتل Storage Blocks بالتتابع ويكتب الناتج إلى OutputStream يملكه المستدعي؛ لا يجمع كل بيانات Bundle في الذاكرة ولا يستخرج ملفات CAB بعد.
- يرفض أنواع الضغط غير المعروفة، والأعلام المجهولة/المشفرة، ويفسر علم 0x200 وفق إصدار المحرك لتجنب الخلط بين padding والتشفير، وأي اختلاف بين مجموع أحجام الكتل المضغوطة وحجم منطقة البيانات.
- الحدود الافتراضية: 64 MiB للكتلة المضغوطة، و64 MiB لناتج الكتلة، و512 MiB لإجمالي الناتج، و64 MiB لـBlock Info، و64 MiB لذاكرة قاموس LZMA، و192 MiB لمجموعة العمل المؤقتة.
- فك مصدر Bundle إلى تدفق إخراج قد يحتوي بيانات جزئية إذا تلفت كتلة لاحقة؛ على المستدعي استخدام ملف مؤقت وعدم اعتماد الناتج إلا بعد نجاح الدالة.
- لا توجد حتى الآن إعادة بناء Bundle أو تعديل موارد أو استخراج ملفات CAB. الاختبارات الحالية Fixtures مصطنعة؛ يلزم التحقق على عينات حقيقية من إصدارات Unity متعددة قبل إعلان التوافق العام.

## حدود الإصدار الحالي — مهم

هذا ليس بعدُ مترجمًا عامًا لكل الألعاب:
- مسار Android Native الحالي يعالج موارد `string` الافتراضية. ومسار assets التجريبي يعالج فقط ملفات JSON/TXT/Properties/Strings النصية الواضحة ضمن المسارات المسموح بها؛ لا يترجم DEX أو الصور أو الصوت أو الملفات الثنائية.
- **Unity Mono: دعم أولي محدود** لملفات JSON/TXT/Properties/Strings الواضحة داخل `assets/bin/Data/StreamingAssets/`، مع اكتشاف Mono ورفض IL2CPP وإعادة بناء ZIP/توقيع APK عبر المسار الحالي. لا يغيّر هذا المسار `Assembly-CSharp.dll` أو `resources.assets` أو AssetBundles. **Unity IL2CPP غير مدعوم بعد**، ولا توجد إعادة بناء لملفات Resources أو AssetBundles.
- **Unreal Engine: غير مدعوم للتعريب حاليًا**؛ الموجود هو اكتشاف مؤشرات فقط. لا يوجد قارئ/كاتب PAK أو IoStore (UCAS/UTOC)، ولا فك ضغط/تشفير أو إعادة بناء الحزم.
- Godot: لا يوجد محول تعريب مكتمل.
- لا يتم حاليًا تعريب `plurals` أو `string-array` أو XML أو ملفات localization الخاصة بمحركات الألعاب.
- **الخطوط: فحص واختيار مبدئي فقط.** يستطيع الإصدار الحالي اكتشاف TTF/OTF وقياس تغطية الحروف العربية، لكنه لا يضمّن خطًا عربيًا بديلًا ولا يبدّل مراجع الخط داخل ملفات اللعبة تلقائيًا. وجود الحروف وحده لا يضمن تشكيل العربية أو RTL؛ يلزم دعم shaping/RTL وربط الخط بمحوّل المحرك. ملفات TTC غير مدعومة في هذا الفحص.
- محرك الترجمة الحالي مضبوط للإنجليزية إلى العربية؛ اختيار اللغة المصدر واكتشافها تلقائيًا قيد التطوير.
- لا يدعم تجاوز DRM أو التشفير أو أنظمة مكافحة الغش.
- التوقيع الجديد مختلف عن توقيع اللعبة الأصلية؛ قد يتطلب تثبيت النسخة المعربة إزالة النسخة الأصلية أولًا، ما قد يؤدي لفقد بياناتها. احتفظ بنسخة احتياطية.

## التشغيل والبناء

- Android 12+ (API 31+).
- إصدار APK الحالي مخصص لمعمارية `arm64-v8a` لتقليل الحجم.
- يلزم تنزيل نموذج ML Kit مرة واحدة عبر Wi-Fi. بعد التأكد من اكتمال تنزيله وتخزينه محليًا، تتم الترجمة على الجهاز دون اتصال ودون إرسال النصوص إلى خادم. فحص APK وقراءة الملفات المحلية لا يحتاجان إنترنت. لا يشمل ذلك تنزيل التطبيق أو نموذج اللغة أول مرة.
- JDK 17 وAndroid SDK 36 وGradle 8.13 للبناء.
